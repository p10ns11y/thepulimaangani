# Plan: Refine Avalokitam Migration - Accurate Parsing and UI Fixes

## Goal
Migrate Avalokitam to modern web stack with accurate Tamil prosody parsing, inspired by the original Quasar Vue.js frontend design.

## Current State
- Basic TanStack Start + React app set up.
- Skeleton Rust WASM parser with dummy output.
- UI shows poor text contrast, no Tamil fonts.
- Parsing returns hardcoded values instead of real analysis.

## Challenges
- Port complex PHP regex-based syllable and foot analysis to Rust.
- Handle Tamil Unicode correctly for graphemes, vowels, consonants.
- Implement metre validation (Venpaa, etc.).
- Design UI to match original's detailed scansion display.

## Plan Phases

### Phase 1: UI Fixes (1-2 days)
- Add Noto Sans Tamil font from Google Fonts.
- Improve text contrast in result display (dark text on light background).
- Structure result output to show hierarchical analysis (lines, feet, syllables).
- Add loading states and error handling.

### Phase 2: Core Parsing Logic (3-5 days)
- Implement GetLetterCount in Rust: count vowels, consonants, mey, etc.
- Port syllable pattern detection (ner/nirai) using regex similar to PHP.
- Implement foot classification (tema, pulima, etc.).
- Add line parsing and metre detection.
- Handle linkages (talai) and ornamentation (todai).

### Phase 3: Advanced Features (2-3 days)
- Port metre validators (CheckVenpaa, etc.) from PHP.
- Add support for multiple lines and complex poems.
- Implement error reporting for invalid metres.

### Phase 4: UI Polish (2 days)
- Create detailed display components for scansion (syllables, feet, linkages).
- Add interactive elements like highlighting syllables.
- Match original's educational style with explanations.

### Phase 5: Testing & Validation (1-2 days)
- Test with sample poems from original app.
- Validate against known Tamil verses.
- Performance optimization for WASM bundle.

## Resources
- Original PHP code in phpbackend/
- C# MenYappu port for reference.
- Original frontend pages (wizard.vue, learn.vue, Prosody.vue) for UI inspiration.

## Success Criteria
- Accurate parsing of sample verses.
- Readable UI with proper Tamil fonts and contrast.
- Performance <2MB bundle, fast analysis.
- Matches original app's analysis quality.
