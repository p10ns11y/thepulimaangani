# Plan: Complete Missing Features and Fix Bugs in thepulimaangani Tamil Prosody Parser

## Overview
Thepulimaangani is a Tamil poetry prosody analyzer that needs completion of missing features and fixes for critical bugs. Current implementation has foundational structure but major issues in core parsing logic.

## Critical Bugs to Fix (High Priority)

### 1. Syllable Text Storage Bug
- **Issue**: Syllables store romanized text instead of original Tamil characters
- **Impact**: Users see romanized output instead of proper Tamil syllables
- **Fix**: Modify `detect_syllables()` to return original Tamil text while using romanized for pattern matching

### 2. Letter Counting Logic
- **Issue**: Vowel/consonant counting is completely broken
- **Impact**: Statistics displayed are meaningless
- **Fix**: Rewrite `get_letter_count()` with proper Tamil Unicode analysis
- **Requirements**: Count actual Tamil characters, not markers; distinguish vowel types

### 3. Syllable Detection Algorithm
- **Issue**: Regex patterns on romanized text don't capture Tamil syllable structure
- **Impact**: Incorrect Ner/Nirai classification
- **Fix**: Implement proper Tamil phonological rules for syllable detection

## Missing Core Features (Medium Priority)

### 4. Complete Foot Type Recognition
- **Issue**: Only basic 2-4 syllable patterns implemented
- **Impact**: Limited metre detection capabilities
- **Add**: Full traditional foot types (5-6+ syllable variations)

### 5. Complete Metre Detection
- **Issue**: Only Venpaa and Venkalippaa supported
- **Impact**: Cannot analyze most Tamil poems
- **Add**: Asiriyappaa, Kalippaa variants, and other major metres

### 6. Vikalpa Support
- **Issue**: No alternative readings support
- **Impact**: Cannot handle ambiguous Tamil text
- **Add**: Multiple parsing possibilities for complex texts

### 7. Complete Talai (Bond) Analysis
- **Issue**: Bond calculation is incomplete with placeholder functions
- **Impact**: Prosodic linkage analysis is inaccurate
- **Fix**: Implement full traditional bond types and rules

## UI/UX Improvements (Lower Priority)

### 8. Input Validation and Error Handling
- **Issue**: No validation for Tamil text input
- **Impact**: Poor user experience with invalid inputs
- **Add**: Tamil text validation, better error messages

### 9. Enhanced Results Display
- **Issue**: Basic result display, no export options
- **Impact**: Limited usability for research/analysis
- **Add**: Export functionality, better formatting, copy features

### 10. User Experience Features
- **Issue**: No examples, help, or guidance
- **Impact**: Hard for users to understand how to use
- **Add**: Sample poems, documentation links, usage examples

## Implementation Strategy

### Phase 1: Core Bug Fixes
1. Fix syllable text storage (romanized → Tamil)
2. Rewrite letter counting logic
3. Fix syllable detection algorithm

### Phase 2: Feature Completion
4. Expand foot type recognition
5. Add missing metre types
6. Implement complete bond analysis
7. Add vikalpa support

### Phase 3: UI/UX Polish
8. Add input validation
9. Enhance result display
10. Add user guidance features

### Phase 4: Testing and Validation
- Add comprehensive test suite
- Validate against known Tamil poems
- Performance optimization

## Technical Approach
- Fix bugs incrementally with tests
- Add features in small chunks
- Maintain backward compatibility
- Follow traditional Tamil prosody rules
- Ensure WASM performance is maintained

## Success Criteria
- Accurate syllable classification for Tamil text
- Correct letter counting and statistics
- Support for all major Tamil metres
- Complete prosodic analysis including bonds
- User-friendly interface with proper Tamil display
