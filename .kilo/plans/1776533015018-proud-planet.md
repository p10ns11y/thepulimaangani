# Plan: Fix Metre Detection Logic for Tamil Prosody Parsing

## Goal
Correct the metre detection to properly identify வெண்கலிப்பா (venkalippaa) instead of incorrectly detecting வெண்பா (venpaa) for the given example text.

## Current Issue
- The example text "ஏர்மலர் நறுங்கோதை எருத்தலைப்ப இறைஞ்சித்தன் வார்மலர்த் தடங்கண்ணார் வலைப்பட்டு வருந்தியவென் தார்வரை அகன்மார்பன் தனிமையை அறியுங்கொல் சீர்மலி கொடியிடை சிறந்து" should be வெண்கலிப்பா but is detected as வெண்பா.
- Root cause: Rust implementation only checks CheckVenpaa, but PHP checks multiple metre validators in order (CheckVenpaa, CheckAsiriyappaa, CheckKalippaa, CheckVenKalippaa, etc.) and returns the first match.

## Analysis from PHP Code
From `GetMetreType()`, metre detection follows this priority order:
1. CheckVenpaa
2. CheckAsiriyappaa  
3. CheckKalippaa
4. CheckVenKalippaa
5. CheckVanjippaa
6. CheckVenInam, etc.

For வெண்கலிப்பா, `CheckVenKalippaa()` checks:
- TotalLines > 3 (4+ lines)
- Most lines have 4 feet (syllables grouped into 4 feet per line)
- Last line has 3 feet
- No disallowed word classes (tEmA, puLimA, etc.)
- TalaiCheck: ≥50% kali+ven bonds total, ≥25% kali bonds specifically

## Implementation Plan

### Phase 1: Implement Multi-Line Parsing
- Update syllable detection to handle multiple lines (split on \n)
- Group syllables into feet per line
- Track line count and feet per line

### Phase 2: Port Metre Validators
- Implement CheckVenKalippaa() logic in Rust
- Add framework for calling multiple metre checks in priority order
- Update ParseResult to include proper metre detection

### Phase 3: Add Talai (Bond/Linkage) Logic
- Port basic talai detection (kali bonds, ven bonds)
- Implement bond counting for metre validation

### Phase 4: Update Metre Type Determination
- Implement GetMetreType() equivalent that calls checks in PHP order
- Return correct metre type based on validation results

### Phase 5: Testing & Validation
- Test with the provided example to ensure venkalippaa detection
- Validate against other sample metres from example.vue

## Success Criteria
- Example text correctly identified as வெண்கலிப்பா
- Metre detection follows PHP priority order
- Maintains compatibility with existing UI display</content>
