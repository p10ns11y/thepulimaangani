# type: குறட்டாழிசை

நண்ணு வார்வினை நைய நாடொறும் நற்ற வர்க்கர சாய ஞானநல்
கண்ணி னானடி யேயடை வார்கள் கற்றவரே

Rules:
- இரு அடிகள் கொண்டிருத்தல் வேண்டும் 
- முதலடி குறைந்தபட்சம் நான்கு சீர்கள் கொண்டிருத்தல் வேண்டும் 
- இரண்டாம் அடி முதலடியை விட குறைவாக இருத்தல் வேண்டும் 
அனைத்து அடிகளிலும் ஒரே அடி எதுகை அமைதல் சிறப்பு

ஆதி உலகிற் காண்

- இரு அடிகளும் ஒரே அளவில் இருத்தல் வேண்டும்

# type: வெண்டாழிசை

நண்பி தென்று தீய சொல்லார்
முன்பு நின்று முனிவு செய்யார்
அன்பு வேண்டு பவர்

- மூன்று அடிகள் கொண்டிருத்தல் வேண்டும் 
- முதல் இருஅடிகள் அளவடியாகவும் ஈற்றடி சிந்தடியாக இருத்தல் வேண்டும் 
- அனைத்து அடிகளிலும் ஒரே அடி எதுகை அமைதல் சிறப்பு 

# type: வெள்ளொத்தாழிசை

ஏரினைப் போற்றுதும்! ஏரினைப் போற்றுதும்!
பாருல கத்தோர் பசிப்பிணிக் கோர்மருந்தாய்
ஆருயி ரோம்புத லான்

கைத்தொழில் போற்றுதும் கைத்தொழில் போற்றுதும்
ஒத்துல கத்தே உயர்வாழ்வுக் கானபொருள்
அத்தனையுந் தான்தருத லான்

வாணிகம் போற்றுதும் வாணிகம் போற்றுதும்
ஏணிபோல் எப்பொருளும் எங்கும்இல் லென்னாமே
ஆணிபோ லேதருத லான்

- சிந்தடி வெண்பாக்கள் மூன்றடுக்கி வருதல் வேண்டும் 

# type: வெண்டுறை

படர்தருவெவ் வினைத்தொடர்பாற் பவத்தொடர்பப் பவதொடர்பாற் படராநிற்கும்
விடலரும்வெவ் வினைத்தொடர்பவ் வினைத்தொடர்புக் கொழிபுண்டோ வினையேற்கம்மா
விடர்பெரிது முடையேன்மற் றென்செய்கே னென்செய்கே
னடலரவ மரைக்கசைத்த வடிகேளோ வடிகேளோ

- மூன்று அடிகள் முதல் ஏழடிகள் வரை கொண்டிருத்தல் வேண்டும் 
- முதல் சில அடிகள் ஒரே அளவையும், பின்வரும் அடிகள் நிலையாக சீர் குறைந்து ஒரே அளவில் வருதல் வேண்டும். 
- பிற அடிகள் குறையாது ஈற்றடி மட்டும் குறைந்தும் வருதலும் உண்டு. 

அனைத்து அடிகளிலும் ஒரே அடி எதுகை அமைதல் சிறப்பு 

# type: வெளிவிருத்தம்

மருள்அறுத்த பெரும்போதி மாதவரைக் கண்டிலனால்! - என்செய்கோயான்!
அருள்இருந்த திருமொழியால் அறவழக்கங் கேட்டிலனால்! - என்செய்கோயான்!
பொருள்அறியும் அருந்தவத்துப் புரவலரைக் கண்டிலனால்! - என்செய்கோயான்!

- மூன்று அல்லது நான்கு நெடிலடிகள் கொண்டிருத்தல் வேண்டும் 
- ஒவ்வொரு அடியிலும் தனிச்சொல் பெற்றிருத்தல் வேண்டும் 
- தனிச்சொற்கள் அனைத்தும் ஒரே சொல்லாக இருத்தல் வேண்டும். 
- ஒவ்வொரு அடியிலும் ஒரே அடி எதுகை அமைதல் வேண்டும்
