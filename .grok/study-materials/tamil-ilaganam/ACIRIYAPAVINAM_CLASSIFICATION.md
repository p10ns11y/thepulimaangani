# ஆசிரியத் தாழிசை

வானுற நிமிர்ந்தனை வையகம் அளந்தனை
பான்மதி விடுத்தனை பல்லுயிர் ஓம்பினை
நீனிற வண்ணநின் நிரைகழல் தொழுதனம்

ஒரே அளவு கொண்ட மூன்று அடிகள் கொண்டிருத்தல் வேண்டும் 
இது மூன்றடுக்காகவும் வரலாம். மூன்றடுக்கிவரின் இது ஆசிரிய ஒத்தாழிசை ஆகும். 
அனைத்து அடிகளிலும் ஒரே அடி எதுகை அமைதல் சிறப்பு 
இது தனித்து வந்த ஆசிரியத்தாழிசை

# ஆசிரியத் தாழிசை

கன்று குணிலாக் கனியுகுத்த மாயவன்
இன்றுநம் ஆனுள் வருமேல் அவன்வாயில்
கொன்றையம் தீங்குழல் கேளாமோ தோழி

பாம்பு கயிறாக் கடல்கடைந்த மாயவன்
ஈங்குநம் ஆனுள் வருமேல் அவன்வாயில்
ஆம்பலந் தீங்குழல் கேளாமோ தோழி

கொல்லையஞ் சாரல் குருந்தொசித்த மாயவன்
எல்லிநம் ஆனுள் வருமேல் அவன்வாயில்
முல்லையந் தீங்குழல் கேளாமோ தோழி

ஒரே அளவு கொண்ட மூன்று அடிகள் கொண்டிருத்தல் வேண்டும் 
இது மூன்றடுக்காகவும் வரலாம். மூன்றடுக்கிவரின் இது ஆசிரிய ஒத்தாழிசை ஆகும். 
ஒவ்வொரு அடுக்கிலும் ஒரே அடி எதுகை அமைதல் சிறப்பு 
இது மூன்றடுக்கி வந்த ஆசிரிய ஒத்தாழிசை

# ஆசிரியத் துறை

இரங்கு குயில்முழவா இன்னிசையாழ் தேனா
அரங்கு மணிபொழிலா ஆடும் போலும் இளவேனில்
அரங்கு மணிபொழிலா ஆடு மாயின்
மரங்கொல் மணந்தகன்றார் நெஞ்சமென் செய்த திளவேனில்

நான்கு அடிகள் கொண்டிருத்தல் வேண்டும் 
குறைந்தபட்சம் ஒரு அடி ஈற்றடியின் நீளத்தை விட குறைவாக வருதல் வேண்டும் 
குறைவாக வராத அடிகள், ஈற்றடியின் அளவை பெற்றிருத்தல் வேண்டும் 
அனைத்து அடிகளிலும் ஒரே அடி எதுகை அமைதல் சிறப்பு 

# அறுசீர் கழிநெடிலடி ஆசிரிய விருத்தம்

தொழும்அடியர் இதயமலர் ஒருபொழுதும் பிரிவரிய துணைவர் எனலாம்
எழும்இரவி கிரணநிகர் இலகுதுகில் புனைசெய்தருள் இறைவர் இடமாம்
குழுவுமறை யவருமுனி வரருமரி பிரமருர கவனும் எவரும்
தொழுகைய இமையவரும் அறம்மருவு துதிசெய்தெழு துடித புரமே!

- கழிநெடிலடிகள் நான்கு கொண்டிருத்தல் வேண்டும் 
- அனைத்து அடிகளிலும் ஒரே அடி எதுகை அமைதல் வேண்டும் 
- அறுசீர்க் கழிநெடிலடி நான்கு கொண்டிருப்பதால் அறுசீர்க் கழிநெடிலடி ஆசிரியவிருத்தம் ஆயிற்று

# எழுசீர் கழிநெடிலடி ஆசிரிய விருத்தம்

தோடார் இலங்கு மலர்கோதி வண்டு வரிபாட நீடு துணர்சேர்
வாடாத போதி நெறிநீழல் மேய வரதன் பயந்த அறநூல்
கோடாத சீல விதமேவி வாய்மை குணனாக நாளும் முயல்வார்
வீடாத இன்ப நெறிசேர்வர்! துன்ப வினைசேர்தல் நாளும் இலரே

- கழிநெடிலடிகள் நான்கு கொண்டிருத்தல் வேண்டும் 
- அனைத்து அடிகளிலும் ஒரே அடி எதுகை அமைதல் வேண்டும் 
- எழுசீர்க் கழிநெடிலடி நான்கு கொண்டிருப்பதால்   
  எழுசீர்க்கழிநெடிலடி ஆசிரியவிருத்தம் ஆயிற்று

# எண்சீர் கழிநெடிலடி ஆசிரிய விருத்தம்

எண்டிசையும் ஆகி இருள்அகல நூறி எழுதளிர்கள் சோதி முழுதுலகம் நாறி
வண்டிசைகள் பாடி மதுமலர்கள் வேய்ந்து மழைமருவு போதி உழைநிழல்கொள் வாமன்
வெண்டிரையின் மீது விரிகதிர்கள் காண வெறிதழல்கொள் மேனி அறிவனெழில் மேவு
புண்டரிக பாதம் நமசரனம் ஆகும் எனமுனிவர் தீமை புணர்பிறவி காணார்

- கழிநெடிலடிகள் நான்கு கொண்டிருத்தல் வேண்டும் 
- அனைத்து அடிகளிலும் ஒரே அடி எதுகை அமைதல் வேண்டும் 
- எண்சீர்க் கழிநெடிலடி நான்கு கொண்டிருப்பதால் எண்சீர்க் கழிநெடிலடி ஆசிரியவிருத்தம் ஆயிற்று
